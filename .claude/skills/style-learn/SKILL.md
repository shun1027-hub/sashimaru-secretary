# 文体の学習

1. `memory/examples/` の投稿文をすべて読む。反応のメモがあれば、反応が良い投稿を重視する。
2. 次の観点で分析する。
   - 書き出しのパターン（疑問形、驚き、数字など）
   - 語尾と口調（です・ます調か、くだけた口調か）
   - 絵文字の使い方（種類、頻度、位置）
   - 改行と箇条書きの使い方
   - 施設情報ブロックの書き方
   - 締めの一言、保存やフォローの促し方
   - ハッシュタグの数と、よく使うタグ
   - よく使う言い回し、避けている表現
3. `memory/style-guide.md` を書き直す。実際の投稿から引用した短い例を各項目に添える。
4. 変更点を3〜5行で報告し、「この理解で合っていますか？」と本人に確認する。
