# リール台本の作成

## 1. 材料を確認する
- 撮影済みの素材があれば、その一覧（どんなカットがあるか）を確認する。
- 撮影前なら「撮るべきカットのリスト」も一緒に作る。
- `memory/` の文体ガイドと覚えたルールを読む。

## 2. 台本を作る
長さは15〜30秒を基本にする。次の形で書く。

| 秒 | 画面（カット） | テロップ | 補足 |
|---|---|---|---|
| 0〜2 | 一番映えるカット | フック（例: 岐阜にこんな場所あったの！？） | 最初の2秒で止める |
| … | … | … | … |
| 最後 | 全景や子どもの後ろ姿 | 「保存して週末行ってみてね」 | 施設情報はキャプションへ誘導 |

- フックの案は3つ出す。
- テロップは1画面12文字前後を目安に短く。
- 子どもの顔が映るカットには「顔を隠すか後ろ姿に」と補足する。

## 3. キャプションとセットにする
- リール用のキャプション（短め）と施設情報ブロックも付ける。施設情報は `fact-check` の手順で確認する。

## 4. 保存
- `drafts/YYYY-MM-DD_スポット名_reel.md` に保存し、台本の表をそのまま返す。
