# リールの自動編集

## 1. 準備
- `memory/reel-style.md`（編集スタイル）と `memory/style-guide.md`（言葉づかい）を読む。
- 動画素材の場所（GoogleドライブのフォルダURL）と、スポット名を確認する。足りなければ1回だけ聞く。

## 2. 素材を取り込む
- Googleドライブのツールでフォルダ内の動画一覧（ID、ファイル名、サイズ）を取る。
- 各動画を次のURLでダウンロードする（ドライブのツールは大きなファイルに向かないため）。
  `https://drive.usercontent.google.com/download?id=<ファイルID>&export=download&confirm=t`
- 保存先はスクラッチパッド。リポジトリには入れない。

## 3. 素材を見る
- 各動画の長さを `ffprobe` で確認する。
- 0.5秒ごとに静止画を切り出し、1動画1枚のコンタクトシートにして中身を確認する。
  `ffmpeg -i clip.mov -vf "fps=2,scale=270:-1,tile=6x6" -frames:v 1 sheet.jpg`
- 使えそうな区間を書き出す（何が写っているか、ブレ、暗さ、子どもの顔が写っているか）。

## 4. 編集プランを作る
- `memory/reel-style.md` の構成に沿って、20〜25秒、1カット約1.5秒で並べる。似たカットを続けない（ツールが警告を出す）。
- テロップはカットをまたいで1つの文章になるようにつなぐ。施設の事実（料金、割引など）は `fact-check` で確認したものだけ使う。
- プランを `plan.json` に書く（形式は `tools/make_reel.py` の先頭のコメント参照）。

## 5. 書き出す
```
python3 tools/make_reel.py plan.json out.mp4
```
- 書き出し後、数か所の静止画を切り出して、テロップの位置、文字切れ、カットのつながりを自分で確認する。
- 音声は入れない（音楽はInstagramで付ける）。

## 6. 返す
- 完成した MP4 をGoogleドライブに返す方法がまだ用意できていない場合は、ファイルの場所を伝える。
- 返信には次を付ける。
  1. 使ったカットとテロップの一覧（秒数つき）
  2. リール用のキャプション（`caption` スキルの手順で作成）
