# リールの下ごしらえ

仕上げの編集（テロップのデザイン、音楽、エフェクト）は本人がCapCutで行う。秘書は、時間がかかる「場面選び」と「文章」を引き受ける。完成動画は作らない（本人の判断 2026-10-28: 全自動の仕上がりは質が足りなかった）。

## 1. 準備
- `memory/reel-style.md` と `memory/style-guide.md` と `memory/learned-rules.md` を読む。
- 動画素材のフォルダURLとスポット名を確認する。足りなければ1回だけ聞く。

## 2. 素材を取り込む
- Googleドライブのツールでフォルダ内の動画一覧（ID、ファイル名、サイズ）を取る。
- 各動画を次のURLでスクラッチパッドにダウンロードする。リポジトリには入れない。
  `https://drive.usercontent.google.com/download?id=<ファイルID>&export=download&confirm=t`

## 3. 素材を見る
- 各動画を1秒ごとに切り出したコンタクトシートにして中身を確認する（秒数を画像に入れる）。
  `ffmpeg -i clip.mov -vf "fps=1,scale=200:-2,drawtext=...:text='%{pts\:hms}',tile=8xN" -frames:v 1 sheet.jpg`
- 何が写っているか、ブレ・暗さ、人物（スタッフなど）を書き出す。同じ映像の重複ファイルにも気づくこと。
- 静止画だけでは手ぶれやカメラの動きは分からないので、怪しい区間は0.25秒ごとに切り出して確認する。

## 4. 構成を決める
- `memory/reel-style.md` に沿って、20〜25秒、1カット約1.5秒、13〜15カット。似たカットを続けない。
- テロップはカットをまたいで1つの文章になるようにつなぐ。施設の事実は `fact-check` で確認したものだけ使う。
- プランを `plan.json` に書く（形式は `tools/make_reel.py` の先頭のコメントと同じ。text に改行を入れてよい）。

## 5. 下ごしらえを書き出す
```
python3 tools/cut_clips.py plan.json <出力フォルダ>
```
- 番号付きクリップ（前後0.4秒の余白つき、色補正なし、元の音声つき）と `storyboard.jpg`（絵コンテ）ができる。
- 絵コンテを自分で見て、カットの中身とテロップが合っているか確認する。
- クリップと絵コンテをzipにまとめる。

## 6. 編集シートを作って返す
- `drafts/reels/YYYY-MM-DD_スポット名_編集シート.md` に次を書く。
  1. CapCutでの手順（番号順に読み込む → 長さを詰める → テロップを貼る → 音楽）
  2. カット表（No.、元素材と秒数、目安の長さ、何が映っているか、テロップ）
  3. 差し替え候補（フックの別案など）
  4. BGMの方向性（曲調、テンポ、CapCutのカテゴリ）
  5. キャプション（`caption` スキルの手順）と事実確認の結果
  6. 本人がやること（★、本音のひとこと、⚠️の確認）
- 絵コンテ、zip、編集シートを SendUserFile で送る。
- `plan.json` も `drafts/reels/` に保存する。

## 補足
- `tools/make_reel.py`（テロップ入りの自動書き出し）と `tools/make_bgm.py`（自動作曲）は、仮のプレビューが欲しいと言われたときだけ使う。
