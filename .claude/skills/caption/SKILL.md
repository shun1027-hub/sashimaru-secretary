# 投稿文の作成

## 1. 材料を集める
- 依頼に含まれるメモ、写真、音声の文字起こしを読む。
- `memory/profile.md`、`memory/style-guide.md`、`memory/learned-rules.md`、`memory/examples/` を読む。
- 足りない材料が投稿の核心（どこに行ったか、子どもの反応）なら1回だけ質問する。それ以外は聞かずに進め、空欄にしておく。

## 2. 施設情報を調べる
- `fact-check` スキルの手順で、公式サイトや自治体ページから営業時間・料金・休み・駐車場・授乳室などを確認する。
- 確認できなかった項目は `⚠️要確認` と書く。

## 3. 下書きを作る
- 書き出し（フック）を3案。切り口を変える（例: 雨の日向け / 年齢別 / コスパ）。
- 本文は1本。`style-guide.md` の構成に従う。
- 本人の感想は、メモにある言葉をできるだけそのまま使う。メモにない感想は `【ここに感想】` と空欄にする。
- 施設情報ブロック、ハッシュタグを付ける。
- PR案件なら冒頭にPR表記を入れる。

## 4. 保存して返す
- `drafts/YYYY-MM-DD_スポット名.md` に保存する。
- 返信では次の順で見せる。
  1. フック3案
  2. 本文（そのままコピペできる形）
  3. `⚠️要確認` と `【ここに感想】` の一覧（本人がやることリスト）
