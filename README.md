# さしまる秘書

@gifukozure_sashimaru の投稿づくりを手伝うAI秘書の設定一式です。
Claude Code でこのフォルダ（リポジトリ）を開くと、秘書として動きます。夫婦どちらが使っても、同じルールと記憶を共有します。

## 使い方（例）
- 「岐阜ファミリーパーク行ってきた。ローラーすべり台に子どもが5回並んだ。雨でも屋根のある場所あった。投稿文作って」
- 「さっきの投稿のリール台本も作って」
- 「この下書き、投稿前チェックして」
- 「過去の投稿を入れたから、文体を覚えて」

写真やスクリーンショットを一緒に送ってもOKです。

## 最初にやること
1. `memory/profile.md` の【 】部分を書き換える
2. `memory/examples/` に反応の良かった過去の投稿文を5〜10本入れる
3. 秘書に「文体を覚えて」と頼む

## フォルダ構成
| 場所 | 中身 |
|---|---|
| `CLAUDE.md` | 秘書の人格とルール |
| `memory/` | アカウント情報、文体ガイド、覚えたルール、過去の投稿 |
| `.claude/skills/` | 投稿文、リール台本、事実確認、文体学習の手順 |
| `drafts/` | 秘書が作った下書き |
