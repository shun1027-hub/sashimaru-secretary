# リールの編集スタイル

> 2026-10-28 に投稿済みリール1本（長良川清流ホテル＋日帰り温泉）を分析して作成。完成版リールが増えたら更新すること。

## 基本仕様
- 縦型 1080x1920、長さ約22秒。
- **1カットは約1.5秒（1.4〜1.9秒）。** 20〜25秒で13〜15カット。
  - 参考リールは0.7〜1秒だったが、本人から「テンポが速すぎる」と指摘あり（2026-10-28）。こちらを優先する。
- **似たカットを続けない。** 同じ素材の近い場面、同じような構図（芝生の引き、など）が続くと飽きる。景色 → アクティビティ → 設備のように、場面と寄り・引きを交互にする。
- **色補正はしない。** 撮ったままの色を使う（本人の希望 2026-10-28）。
- **BGMを付けて書き出す**（本人の希望 2026-10-28）。`tools/make_bgm.py` で作るオリジナル曲（著作権フリー）を使う。素材の音声は使わない。

## 構成（22秒の流れ）
| 秒 | 内容 | テロップ例 |
|---|---|---|
| 0〜2 | フック。一番映える寄りのカット（料理、湯気など）に、大きめのテロップを4行重ねる | `✿期間限定✿` / `春にやりたい` / `親子で楽しむ和体験` / `岐阜県` |
| 2〜6 | 入口から中へ。空間の紹介 | `のれんをくぐると` → `そこは懐かしさ感じる` → `ほっこり和空間` |
| 6〜12 | メインの体験。素材 → 子どもが体験する手元 → 子どもの反応 | `旬のフルーツ×求肥で` → `オリジナル大福作り` → `求肥はぷにぷにして` → `気持ちいい〜😊` → `出来立て食べれるの最高やない？😍` |
| 12〜15 | サブの体験 | `くるくる混ぜて` → `お抹茶まで出来る` |

| 18〜21 | 雰囲気・景色で余韻 | `いつもと違う` → `ちょっと特別なおでかけ` → `体験してみん？` |
| 21〜22 | 締め。外観＋施設名カード | `『長良川清流ホテル』` / `岐阜県岐阜市` |

## テロップ
- **1カットに短い1フレーズ**（6〜12文字）。カットをまたいで1つの文章になるように、ナレーションのようにつなぐ。
- 口調は話し言葉で、方言まじり（「〜やない？」「〜してみん？」）。
- 位置は画面中央よりやや上（高さの35〜45%あたり）。
- 丸ゴシックの太字、白文字に色の縁取りと光彩。本編はピンク、締めの施設名カードは青。
- フックは `✿ラベル✿`（期間限定など）＋2行のキャッチ＋エリア名。
- 締めは `『施設名』` と `市町村名`（📍付き）。

## カット選び
- フックは「寄り」の一番映えるカット。
- 子どもは**手元**のアップが多い。体験の様子、食べる瞬間の表情も使っている。
- 締めは、施設の外観に向かって子どもが歩く・走る**後ろ姿**。
- 景色（川、山など）は余韻のパートで使う。

## 子どもの顔
- **子どもが写っていてよい**（本人確認済み 2026-10-28）。楽しそうな表情のカットは、フックにも積極的に使う。
