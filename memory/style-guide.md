# 文体ガイド

> 2026-10-28 に過去投稿1本（南濃温泉 水晶の湯）から作成。サンプルが1本だけなので、投稿を追加したら `style-learn` で更新すること。

## 全体の印象
- 友だちに話しかけるような、やわらかい口調。「〜だよ」「〜しちゃうよ」「〜してみてね」。
- **施設の魅力を紹介する情報型**。本人の体験談や子どもの細かい反応は本文の主役ではない（「子どもと一緒に楽しめちゃうよ」程度）。
- 1行は短く（15文字前後）、意味の切れ目でこまめに改行する。段落の間は1行空ける。

## 書き出し（フック）
- **`＼ 〇〇 ／` の囲みで始める。** 数字（料金など）と驚きの「！？」を入れ、最後に絵文字1つ。
  - 例: `＼650円でこの絶景！？♨️／`
- 続く2行で「どんな場所か」と「子連れ向け」であることを伝え、✨で締める。
  - 例: `山の上にある` / `子連れで行きたい温泉スポット✨`

## 本文の構成
1. フック（囲み）＋2行の説明
2. 場所の紹介: `ここは、〇〇市にある` / `「施設名」` ＋ジャンルの絵文字
3. 魅力を**1段落に1つずつ**、3〜4段落で紹介する。箇条書きや✔️は使わない。
   - 子連れ目線の一言を混ぜる（例: 移動の時間も子どもと楽しめる）
   - 具体的な数字を入れる（標高約150m、11種類のお風呂など）
4. `そしてなんといっても` で一番の推しポイントを強調する。
5. 周辺のおすすめ（近くの公園、散歩コースなど）を一言。
6. 締め: `家族でのお出かけ先に` / `ぜひチェックしてみてね☺️`

## 絵文字
- 各段落の最後に1つだけ付ける。文中には入れない。
- よく使う: ☺️ ✨ 🌿 🚍 と、スポットのジャンルに合ったもの（温泉なら♨️）。
- ジャンルの絵文字はフック、施設名の後、施設情報の見出しで繰り返し使う。

## 施設情報ブロック
本文の後に区切り線 `➳━━━━━━━━━━━━━━━━━━` で囲む。項目の間は1行空ける。

```
➳━━━━━━━━━━━━━━━━━━

（ジャンル絵文字） 施設名

📍 都道府県から始まる住所（番地まで）

🕐 営業時間
10:00〜21:00
（最終受付20:30）

💰 料金名（入浴料金・入園料など）

区分名
・大人（12歳以上）　平日〇円／休日〇円
・小人（3歳以上12歳未満）　平日〇円／休日〇円
※補足

🅿️ 無料駐車場あり（〇台）
※補足

📅 休館日
毎月第1木曜日
※祝日の場合は〜

☎️ 電話番号

⚠️ 料金や営業時間などは変更になる場合があります。
お出かけ前に最新情報をご確認ください。

➳━━━━━━━━━━━━━━━━━━
```
- 見出しの後は改行して内容を書く（営業時間、料金、休館日）。1行で済むもの（住所、駐車場、電話）は見出しと同じ行。
- 料金は年齢区分を明記する。市民割引などがあれば別の区分として書く。
- 施設特有の情報（シャトルバスなど）は、合う絵文字で1項目足す。
- ⚠️ の注意書きは毎回この文言で固定。

## 自己紹介ブロック（固定）
施設情報の後に「さしまるって？」で始まる自己紹介を毎回付ける。内容は固定文なので、`memory/self-intro.md` から**そのまま**コピーする。改変しない。
