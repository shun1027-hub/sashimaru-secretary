# 文体ガイド

> 2026-10-28 に過去投稿2本（南濃温泉 水晶の湯／各務原市民プール）から作成。投稿を追加したら `style-learn` で更新すること。
> 2本で書き方に違いがある部分は「型A（水晶の湯）」「型B（市民プール）」として両方残している。⚠️どちらが今の書き方か本人に確認中。確認が取れるまでは型Aを基本にする。

## 全体の印象（2本に共通）
- 友だちに話しかけるような、やわらかい口調。「〜だよ」「〜しちゃうよ」「〜してみてね」「〜できる😊」。
- 1行は短く（15〜20文字前後）、意味の切れ目でこまめに改行する。段落の間は1行空ける。
- 子連れ目線を必ず入れる（年齢別に遊べる、おむつの子もOK、移動も子どもと楽しめる、など）。
- 具体的な数字を積極的に入れる（全長180m、11種類、5連すべり台、標高約150m）。
- 情報が中心。ただし行ったことがある場所では、実体験を短く添える（例: 「我が家も去年からめちゃくちゃお世話になってて」）。

## 書き出し（フック）
- 型A: `＼ 〇〇 ／` の囲みで始める。数字と「！？」を入れ、最後に絵文字1つ。続く2行で「どんな場所か」と「子連れ向け」を伝え✨で締める。
  - 例: `＼650円でこの絶景！？♨️／` → `山の上にある` / `子連れで行きたい温泉スポット✨`
- 型B: 1行目に印象的なキャッチコピー＋絵文字。続けて期間などの要点、ひとことの評価、`👉🏻施設名`。
  - 例: `次世代まで引き継ぎたい市民プール🐬` → `今年は9/6まで！` / `コスパ最強プール🏊‍♀️✨` / `👉🏻各務原市民プール`

## 本文
- 型A: 場所の紹介（`ここは、〇〇市にある` / `「施設名」`）→ 魅力を1段落に1つずつ → `そしてなんといっても` で一番の推し → 周辺のおすすめ → `家族でのお出かけ先に` / `ぜひチェックしてみてね☺️`
- 型B: 実体験のひとこと → 設備やエリアを列挙 → 子連れポイント → 注目情報 → 呼びかけ（`ぜひチャレンジしに来てね✨`）
- **並列の情報（設備の種類、イベントなど）は列挙してよい。**
  - 設備の一覧は `〇〇はこちら👇` の後に `・` で列挙する。
  - 項目ごとに説明を付けるときは `✅項目名` を見出しにする。
- 使えない設備などの注意は `⚠️` で1行。補足は `※`。
- 強調したいお知らせ（新イベントなど）は、**型Aとは逆向きの囲み**で3行にする。
  ```
  ／
  そして！今年初！！
  新イベント情報📣
  ＼
  ```
- イベント情報は 📅日程 🕐時間 🧒対象 💰参加費 👥定員 ☎️申込方法 の順で、1項目1行。

## 絵文字
- 各段落・各行の最後に付ける。文中には入れない。
- よく使う: ☺️ ✨ 😊 🙌 🙆‍♀️ 💡 ✌🏻 🌿、スポットのジャンルに合ったもの（温泉♨️、プール🐬🏊‍♀️）。
- ジャンルの絵文字は、フックと施設名で繰り返し使う。

## 施設情報ブロック
- 本文の後に区切り線で囲む。型Aは `➳━━━━━━━━━━━━━━━━━━`、型Bは `-——————`。⚠️どちらが今の形か確認中。
- 1行目は施設名（型Aはジャンル絵文字付き）。項目の間は1行空ける。
- 項目と順番の目安:
  ```
  📍 都道府県から始まる住所（番地まで）

  🕐 営業時間（期間限定なら期間も）
  9:00〜18:00（入場は17:00まで）

  📅 休館日 ／ 🚫休業日
  内容
  ※補足

  💰 料金名
  区分ごとに1行（大人・小人、一般・小中学生・未就学児など）
  ※割引や免除

  🅿️ 無料駐車場あり（台数が分かれば）

  ☎️ 電話番号
  ```
- 施設特有の情報（シャトルバスなど）は、合う絵文字で1項目足す。

## 締めの注意書き
- 型A: `⚠️ 料金や営業時間などは変更になる場合があります。` / `お出かけ前に最新情報をご確認ください。`（施設情報ブロックの中）
- 型B: `参考になれば嬉しいです！！` / `※行かれる際には再度公式HPやInstagram等でご確認ください🙏`（区切り線の後）

## 自己紹介ブロック
- 型Aでは施設情報の後に「さしまるって？」の自己紹介を付けている。`memory/self-intro.md` から**そのまま**コピーし、改変しない。
- 型Bには付いていない。⚠️毎回付けるか確認中。

## ハッシュタグ
- 1行に1つ。4つ前後と少なめ。
- 定番: `#岐阜ママ` `#岐阜子連れ` ＋ジャンル（`#岐阜イベント` など）＋ `#施設名`
