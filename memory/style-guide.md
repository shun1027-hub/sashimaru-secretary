# 文体ガイド

> 2026-10-28 に過去投稿3本（南濃温泉 水晶の湯／各務原市民プール／まねきねこ大垣店）から作成。投稿を追加したら `style-learn` で更新すること。
> 書き出しや区切り線は投稿ごとに変えているので、1つの型に固定しない。下の「共通ルール」は必ず守り、「バリエーション」はスポットに合わせて選ぶ。

## 共通ルール（3本すべてに共通）
- 友だちに話しかけるような、やわらかい口調。「〜だよ」「〜できる」「〜してみてね」「〜してみて😊」。
- 1行は短く（15〜20文字前後）、意味の切れ目でこまめに改行する。段落の間は1行空ける。
- **1行目で一番の売り（数字・お得感・希少性）を言い切る。** 例: 650円で絶景、コスパ最強、時間無制限＆食べ放題、岐阜県内でここだけ。
- 子連れ目線を必ず入れる（年齢別に遊べる、おむつの子もOK、キッズルームで小さい子連れでも安心、親子でゆっくり過ごせる）。
- 具体的な数字を積極的に入れる（全長180m、11種類、5連すべり台、標高約150m）。
- 本文 → 区切り線で囲んだ施設情報 → 自己紹介 → ハッシュタグ、の順。
- 絵文字は行・段落の最後に付ける。文中には入れない。

## 本音のひとこと
- 行ったことがある場所では、実体験や本音を短く添える。読者の信頼につながる部分なので、**本人のメモにあるときだけ**書く。
  - 例: 「我が家も去年からめちゃくちゃお世話になってて」
  - 例: 「清潔感は目を瞑れる方のみ！笑」（気になる点も正直に、軽く笑いにする）

## 書き出しのバリエーション
フック案を3つ出すときは、型を混ぜて出す。
1. 囲み型: `＼650円でこの絶景！？♨️／` → `山の上にある` / `子連れで行きたい温泉スポット✨`
2. キャッチコピー型: `次世代まで引き継ぎたい市民プール🐬` → `今年は9/6まで！` / `コスパ最強プール🏊‍♀️✨` / `👉🏻各務原市民プール`
3. 売り言い切り型: `時間無制限＆食べ放題🍿🍦` → （空行）→ `岐阜県内でここだけ✨`

## 本文の組み立て
- 魅力は1段落に1つ。`しかも`、`そしてなんといっても` で畳みかけて一番の推しを強調する。
- **並列の情報は列挙してよい。** 設備の一覧は `〇〇はこちら👇` の後に `・` で並べる。項目ごとに説明を付けるときは `✅項目名` を見出しにする。
- 使えない設備などの注意は `⚠️` で1行。補足は `※`。
- 強調したいお知らせ（新イベントなど）は逆向きの囲みで3行にする: `／` / `そして！今年初！！` / `新イベント情報📣` / `＼`
- イベント情報は 📅日程 🕐時間 🧒対象 💰参加費 👥定員 ☎️申込方法 の順で1行ずつ。
- 締めは季節や読者への呼びかけ。例: `家族でのお出かけ先に` / `ぜひチェックしてみてね☺️`、`この夏休み、ぜひ行ってみて😊🍉`

## 絵文字
- よく使う: ☺️ ✨ 😊 🙌 🥹 💕 ♪ 🙆‍♀️ 💡 ✌🏻 🌿
- ジャンルや季節に合ったものを足す（温泉♨️、プール🐬🏊‍♀️、食べ放題🍿🍦🥤、夏🍉）。
- お得情報は `🉐〜🉐` で挟む。

## 施設情報ブロック
- 区切り線は `——————————`（全角ダッシュ）を基本にする。過去には `➳━━━━━━` や `-——————` も使っている。
- 1行目は施設名（店舗名・支店名まで）。その下はすぐ 📍住所。
- 住所は郵便番号があれば `〒` から書き、都道府県から番地まで。
- 項目の目安:
  ```
  📍〒000-0000 岐阜県〇〇市〇〇

  🕒営業時間
  曜日や期間ごとに1行
  定休日：〇〇（休みは独立させて 📅休館日 / 🚫休業日 にしてもよい）

  💰料金（または 🍭おかしバー など、サービス名を見出しにしてもよい）
  ・区分ごとに1行（大人・小人、13歳以上・13歳未満など。税込なら明記）
  🉐割引・無料の条件🉐

  🅿️無料駐車場あり（台数が分かれば）

  ☎️電話番号

  ⚠️別料金のもの、店舗による違いなどの注意
  ```
- 施設特有の情報（シャトルバスなど）は、合う絵文字で1項目足す。
- 最新情報の確認のお願いを1行入れる。例: `⚠️ 料金や営業時間などは変更になる場合があります。お出かけ前に最新情報をご確認ください。`

## 自己紹介ブロック
- 施設情報の後に、`memory/self-intro.md` の文章を**そのまま**付ける。改変しない。

## ハッシュタグ
- 1行に1つ、4〜5個と少なめ。
- 定番: `#岐阜ママ` `#岐阜子連れお出かけ` `#岐阜子連れスポット` `#岐阜子連れ`
- ＋ジャンル（`#岐阜イベント` など）＋ `#施設名`（店舗名まで。例: `#まねきねこ大垣店`）
