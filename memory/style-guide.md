# 文体ガイド

> ⚠️ まだ仮の内容です。`memory/examples/` に過去の投稿文を入れて「文体を覚えて」と頼むと、秘書がこのファイルを書き直します。

## 書き出し（1行目）
- フィード上で切れる前の1〜2行で「行きたい」と思わせる。
- 例: 「雨の日でも1日遊べる！岐阜の屋内あそび場🌈」

## 本文の構成（仮）
1. フック（1〜2行）
2. おすすめポイント（3つ前後、箇条書き）
3. 本人の感想（子どもの反応など）
4. 施設情報ブロック
5. 保存・フォローを促す一言
6. ハッシュタグ

## 施設情報ブロック（仮フォーマット）
```
📍 場所：
🕘 営業時間：
📅 休み：
💰 料金：
🚗 駐車場：
🍼 授乳室・おむつ替え：
👶 ベビーカー：
🍙 飲食：
```

## ハッシュタグ（仮）
- 10〜15個。地域タグ（#岐阜子連れ #岐阜おでかけ など）、ジャンルタグ、規模の大きいタグを混ぜる。
